# MARCUS-01 — Project Requirements

## Project Purpose

Design, build, and document a mobile AI-powered server robot as a two-year educational engineering and IT portfolio project.

## Project Constraints

- Project duration: 24 months
- Start date: November 2026
- Target completion: October 2028
- Monthly budget: $125
- Total planned budget: $3,000
- Construction will progress alongside college coursework and certification studies.

## Mechanical Requirements

- Approximately 42 inches tall
- Capsule-shaped chassis
- Two independently powered side wheels
- Concealed rear stabilizing caster
- Low-mounted battery compartment
- Removable service panels
- Accessible internal electronics rack

## Computing Requirements

- Linux-based computing environment
- Raspberry Pi integration
- Mini PC for local AI processing
- SSD storage
- Wired and wireless networking
- Remote system administration

## MOXXI AI Requirements

- Voice interaction
- Expressive digital face
- Speech recognition and voice synthesis
- System diagnostics
- Hardware monitoring
- Configurable personality
- Safe separation between AI functions and motor safety controls

## Safety Requirements

- Physical emergency-stop system
- Appropriate electrical protection
- Battery monitoring
- Thermal management
- Supervised initial driving tests
- Stability testing before outdoor operation

## Documentation Requirements

- GitHub repository
- Engineering journal
- Mechanical drawings
- Electrical diagrams
- Network diagrams
- Software documentation
- Testing records
- Photographs and demonstration videos

## Current Project Status

**Phase 1 — Planning and Design**

Initial project requirements established. Detailed mechanical, electrical, and software designs are pending validation.
