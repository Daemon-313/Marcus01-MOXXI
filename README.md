# MARCUS-01 | MOXXI

### Mobile AI Server & Robotics Engineering Project

**Project Timeline:** November 2026 – October 2028  
**Project Budget:** $3,000 over 24 months  
**Current Phase:** Phase 1 — Planning & Design

## Project Overview

MARCUS-01 is a two-year personal engineering project focused on designing and building a mobile AI-powered server robot.

The robot will combine robotics, Linux system administration, computer networking, Python programming, artificial intelligence, and cybersecurity.

The onboard AI assistant, MOXXI, will provide voice interaction, facial expressions, system diagnostics, and hardware monitoring.

## Planned Hardware

- 42-inch capsule-style chassis
- Two powered side wheels and concealed stabilizing caster
- 24V battery system
- Raspberry Pi computing modules
- Mini PC for AI processing
- SSD storage
- Ethernet and Wi-Fi networking
- Dome-mounted facial display
- Microphones, speakers, and sensors
- Custom cyberpunk exterior

## Project Objectives

1. Design and construct a mobile robotic chassis.
2. Develop a locally hosted AI assistant.
3. Build a portable Linux server environment.
4. Configure secure network infrastructure.
5. Integrate hardware monitoring and diagnostics.
6. Document all engineering decisions and testing.
